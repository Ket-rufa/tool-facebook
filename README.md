# tool-facebook

Starter desktop app using **Go + Wails + Vue 3 + vue-i18n**.

## Stack
- Go 1.22+
- Wails v2
- Vue 3 + Vite + TypeScript
- vue-i18n

## Features in this starter
- Wails desktop shell
- Vue 3 frontend
- Basic Go backend binding
- Multilingual UI: `vi` + `en`
- GitHub Actions CI

## Quick start

### 1) Install prerequisites
- Go
- Node.js 18+
- Wails CLI

```bash
go install github.com/wailsapp/wails/v2/cmd/wails@latest
```

### 2) Install frontend deps
```bash
cd frontend
npm install
cd ..
```

### 3) Run dev mode
```bash
wails dev
```

### 4) Build app
```bash
wails build
```

## Multi-language structure

```text
frontend/src/i18n/
├─ index.ts
└─ locales/
   ├─ en.ts
   └─ vi.ts
```

## Project structure
- `main.go`: app entrypoint
- `app.go`: backend methods exposed to frontend
- `wails.json`: Wails config
- `frontend/`: Vue UI
- `internal/app/`: business logic
- `.github/workflows/`: CI

## Notes
- `frontend/wailsjs/` is generated by Wails at runtime.
- Update app metadata in `wails.json` before release.
